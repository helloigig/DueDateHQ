How to use

Designed badges: Original circular icons distilled from each state's most recognizable visual signature — bear and red star for California, lone star for Texas, Zia sun for New Mexico, and so on. 19 of 50 are drawn so far; the rest sit empty awaiting design. To draft another, add an entry to the stateBadges object keyed by lowercase-hyphenated state name, with an inline SVG string as its value.

Auto-populated: Flags, seals, and outlines for all 50 states are pulled live from Wikimedia Commons (public-domain government works). They appear automatically when the page loads.

Needs manual sourcing: License plates, route shields, quarters, welcome signs, and capitol photos. These are either copyrighted photographs or have inconsistent file naming on Wikipedia. To add one, locate the stateImages override object near the bottom of this file and paste an image URL or local path against the matching state and category key. Save and reload.

Slots accept any web-renderable format (.svg, .png, .jpg, .webp). If a Wikimedia auto-load fails (rare naming exception), the slot reverts to its empty state automatically. Use the search bar to filter by state name.
