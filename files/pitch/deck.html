CPA 的专业判断 + 法律责任
「这笔算不算 capital gain」
「你 audit 风险高不高」
「这条 IRS 法规怎么解读」
最关键的一条规则 — 「AI 永不自动确认客户材料齐了」 — 不是产品文案，是数据库约束：
-- AI 永远不能把状态推到 received_confirmed -- 必须有人类确认者，否则 DB 拒绝 ALTER TABLE checklist_item ADD CONSTRAINT human_must_confirm CHECK ( state != 'received_confirmed' OR confirmed_by_user_id IS NOT NULL );
即使应用层代码出 bug，DB 也拒绝。客户可以查代码，这是结构性承诺，不是营销话术。
