# UI Audit — 2026-05-05

## Scope

Walked every route + chrome surface against:

1. **Existing [DESIGN.md](DESIGN.md)** (1209 lines, Mercury-aligned via prior refresh passes).
2. **NEW OKLCH substrate** (canonical token set added today, §Design substrate). Next-action accent flips **indigo → primary green**, dark mode is first-class, semantic shadcn tokens replace hex.
3. **NEW Mercury-deep additions** (added today): `<MoneyValue>` cents-superscript, pastel avatar variants, lavender / pink / peach `<StatusPill>` family, `<FilterChip chip-soft>` variant, `<NotificationCard>`, `<HelpFab>`.

Pages walked at 1440×900 desktop with mock-mode demo data populated. Routes covered: `/login`, `/`, `/alerts`, `/timeline`, `/clients`, `/clients/:id`, `/clients/:id/tasks/:taskId`, `/calendar`, `/mail`, `/opportunities`, `/settings`, `/settings/team`, `/settings/notifications`, `/import`. Chrome covered: Sidebar, TopBar, BellDropdown, Command palette (⌘K), the import-wizard confirm modal.

Not covered in this pass (out of scope or skipped for time): `/signup`, `/magic-link`, `/forgot-password`, `/reset-password`, `/accept-invite`, the 7 onboarding steps after the wizard, all 25+ task-flow modals (only the import-confirm modal was opened), responsive breakpoints, screen reader / keyboard nav. Recommendations: see §F sprint plan.

### Flip plan (recommended single PR)

1. [components.json](components.json) → `cssVariables: true`.
2. [src/index.css](src/index.css) → paste `:root` + `.dark` blocks into `@layer base`.
3. [tailwind.config.js](tailwind.config.js) → replace hex `colors:` with token-pass-through:
   ```js
   colors: {
     background: 'oklch(var(--background))',
     foreground: 'oklch(var(--foreground))',
     primary: { DEFAULT: 'oklch(var(--primary))', foreground: 'oklch(var(--primary-foreground))' },
     // … full semantic set …
     // legacy aliases (keep JSX compiling on flip day; codemod renames in follow-up PR):
     indigo: { DEFAULT: 'oklch(var(--primary))', hover: 'oklch(var(--primary) / 0.9)', soft: 'oklch(var(--accent))', ink: 'oklch(var(--accent-foreground))' },
     ink: { 900: 'oklch(var(--foreground))', 700: 'oklch(var(--foreground) / 0.7)', 500: 'oklch(var(--muted-foreground))', 400: 'oklch(var(--muted-foreground) / 0.6)', 300: 'oklch(var(--border))' },
     canvas: 'oklch(var(--background))',
     surface: 'oklch(var(--card))',
     sunken: 'oklch(var(--secondary))',
     line: 'oklch(var(--border))',
   }
   ```
4. Add `<ThemeProvider>` mount in [src/main.tsx](src/main.tsx); sun/moon toggle somewhere ergonomic.
5. Smoke-test every route at light + dark.
6. **Follow-up codemod PR:** rename `bg-indigo*` → `bg-primary*`, `ring-indigo` → `ring-ring`, `bg-canvas` → `bg-background`, `bg-surface` → `bg-card`, `text-ink-900` → `text-foreground`, etc., across [src/](src/).

## Section E — What's working well (do not change)

- **Density rhythm.** Every page honors the 8 / 16 / 24 / 48 spacing ladder. No drift.
- **Sidebar.** Floating-card treatment, position 2 for Alerts, account entrance bottom-left — all per spec, all reading correctly.
- **Page headers.** Every page uses `<PageHeader>` with display typography + meta. No drift.
- **Status pills.** No row tinting, no full-card status paint — T4 holds across the product.
- **Banner discipline.** "What changed" banner on Today, "State alert" banner on Clients, info banner on ClientDetail — all distinct in tone, none competing.
- **Modal hygiene.** Backdrop, padding, footer alignment all match §Modals spec.
- **Voice.** No "All caught up!" celebrations spotted in screenshots; verb+object actions ("Send reminder", "Mark complete"); date-only deadlines.
